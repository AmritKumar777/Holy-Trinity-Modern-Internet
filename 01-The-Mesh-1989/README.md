## Ⅰ. Technical Framework: The "Web Formula"
The World Wide Web (WWW) is a high-level application service operating via the synthesis of content-formatting and data-delivery protocols.
## 📐 The Primary Equation
$$\text{WWW} = (\text{HTML} + \text{URL}) + (\text{HTTP} + \text{TCP} + \text{IP} + \text{DNS})$$ 
## 🧱 Component Definitions

* HTML (Content Layer): Semantic markup used to structure information.
* URL (Addressing System): Unique identifier for a specific resource node.
* HTTP (Exchange Protocol): The request/response "handshake."
* TCP/IP (Transmission Stack): Packet-switching and routing mechanism.
* DNS (Resolution Service): Distributed database for IP translation.

------------------------------
## Ⅱ. The Layered Abstraction (OSI Model)
We use the "Sausage Pizza" mnemonic to map data flow from the Human to the Hardware.
Mnemonic: "Please Do Not Throw Sausage Pizza Away" (Layer 1 ➡️ 7)

| OSI Layer | Name | Component | Functional Role |
|---|---|---|---|
| 7 | Application | HTML / HTTP | User interface & logic. |
| 4 | Transport | TCP | The "Truck" (Delivery). |
| 3 | Network | IP / DNS | The "Map" (Routing). |
| 1/2 | Physical | Fiber / Wi-Fi | The "Road" (Signals). |

Note: In the real-world TCP/IP Model, Layers 5-7 are squashed into one Application Layer.

## Ⅲ. Critical Distinctions: Internet vs. WWW
The INTERNET is the Road: The hardware, copper wires, and TCP/IP rules (Created 1960s/70s).
The WEB is the Car: The service, HTML pages, and HTTP protocol (Created 1989/90).

| Service | Is it "Web"? | Is it "Internet"? |
|---|---|---|
| Wikipedia | ✅ YES | ✅ YES |
| Online Gaming | ❌ NO | ✅ YES |
| WhatsApp/Discord | ❌ NO | ✅ YES |
